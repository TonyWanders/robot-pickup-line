A program that writes one robot pickup line to `/output/entry.txt`,
for the make.fun competition
[The Robot Pickup Line Championship](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 125 characters, inside the 1 to 200 gate,
a single line with no em dash.

## The line

```
I don't have a heart, just a battery, and it has been at 100% since you walked in. My cooling fan finds that very suspicious.
```
